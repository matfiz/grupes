The symmetric group: cycles, classes and sign

We follow points through a permutation to write it as a product of disjoint cycles. The cycle lengths then give its conjugacy class, its order and its sign. We use these data to find the normal subgroups of the symmetric group on four points.

Where we are

A cycle sends each entry to the next and its last entry back to the first (§1.2). The conjugacy class of ggg has size [G:CG(g)]\idx{G}{\Cent{G}{g}}[G:CG​(g)] in a finite group (Theorem 3.3). Once we know the classes, a normal subgroup must contain the whole class of each of its elements (Proposition 4.3). The pairing action gave S4=V4⋊(S4)4\SG{4}=\Kl\sdp\Stab{(\SG{4})}{4}S4​=V4​⋊(S4​)4​ (§5.4).

6.2 Conjugacy classes

Conjugation changes the labels of the points. We use this to compare permutations of the same type. To count them, we first need to know how many ways one permutation can be written in the same cycle slots.

Summary

  • Every permutation decomposes into disjoint cycles on the orbits of its powers. The least common multiple of the lengths gives its order (Proposition 6.2).
  • The classes of Sn\SG{n}Sn​ are indexed by cycle type μ\muμ. The centraliser order is zμ\zmu{\mu}zμ​ and the class size is n!/zμn!/\zmu{\mu}n!/zμ​ (Theorem 6.4).
