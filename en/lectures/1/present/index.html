Lecture 1

Groups acting

The course asks what the structure of a finite group is, and how its linear representations reflect it. This lecture defines groups and sets up the basic tool of the course, a group acting on a set. From its main result, orbit–stabiliser, follow Lagrange’s theorem, the class equation, orbit counting and Cauchy’s theorem.

1.1 Groups, subgroups, homomorphisms

This course studies finite groups, the algebra of symmetry. We begin with an example that shows what a group is, the symmetries of an equilateral triangle.

A symmetry of the triangle is an orthogonal map of the plane that carries it to itself. The triangle is centred at the origin, with vertices numbered anticlockwise: The arrow shows the rotation rrr by 2π/32\pi/32π/3, which moves the vertices 1↦2↦3↦11\mapsto2\mapsto3\mapsto11↦2↦3↦1. The dashed line is the axis of the reflection sss, which fixes vertex 111 and exchanges vertices 222 and 333.

Symmetries can be composed. The product rsrsrs means first sss, then rrr, and the result is again a symmetry. Composition of maps is associative. The identity map is a symmetry, and every symmetry can be undone by its inverse map, which is also a symmetry. A group is any set with a product that has these properties.

Definition 1.1 (Group). A group is a set GGG with a product G×G→GG\times G\to GG×G→G, (g,h)↦gh(g,h)\mapsto gh(g,h)↦gh, such that

  • (gh)k=g(hk)(gh)k=g(hk)(gh)k=g(hk) for all g,h,k∈Gg,h,k\in Gg,h,k∈G;

  • there is an identity e∈Ge\in Ge∈G, with eg=ge=geg=ge=geg=ge=g for all g∈Gg\in Gg∈G;

  • each g∈Gg\in Gg∈G has an inverse g−1∈Gg^{-1}\in Gg−1∈G, with gg−1=g−1g=egg^{-1}=g^{-1}g=egg−1=g−1g=e.

The order ∣G∣\abs{G}∣G∣ of GGG is its number of elements. The group GGG is abelian if gh=hggh=hggh=hg for all g,h∈Gg,h\in Gg,h∈G.

The definition asks for an identity and for an inverse of each element. We first check that each of them is unique, so that the symbols eee and g−1g^{-1}g−1 name definite elements. If eee and e′e'e′ are identities, then e=ee′=e′,\begin{aligned} e=ee'=e', \end{aligned}e=ee′=e′,​ first because e′e'e′ is an identity and then because eee is. The main examples of this course are the groups of all bijections of a set.

1.2 Actions

In Example 1.6 the elements of D3\Dih{3}D3​ move the vertices of the triangle. An action describes this situation for any group and any set. Each group element moves the points of the set, and a product moves them as its factors do, one after the other.

Definition 1.7 (Action). A (left) action of GGG on a set XXX is a map G×X→XG\times X\to XG×X→X, (g,x)↦g⋅x(g,x)\mapsto g\cdot x(g,x)↦g⋅x, with e⋅x=x,g⋅(h⋅x)=(gh)⋅x\begin{gathered} e\cdot x=x,\\ g\cdot(h\cdot x)=(gh)\cdot x \end{gathered}e⋅x=x,g⋅(h⋅x)=(gh)⋅x​ for all g,h∈Gg,h\in Gg,h∈G and x∈Xx\in Xx∈X. The set XXX is then a GGG-set.

Two sets describe what the group does to a point: the points it can be moved to, and the group elements that leave it in place. We say that ggg fixes xxx if g⋅x=xg\cdot x=xg⋅x=x.

Definition 1.8 (Orbit and stabiliser). Let GGG act on XXX, and let x∈Xx\in Xx∈X. The orbit of xxx is G⋅x={g⋅x:g∈G}G\cdot x=\{g\cdot x:g\in G\}G⋅x={g⋅x:g∈G}. The stabiliser of xxx is Gx={g∈G:g⋅x=x}\Stab{G}{x}=\{g\in G:g\cdot x=x\}Gx​={g∈G:g⋅x=x}. The action is transitive if there is one orbit.

Example 1.9 (D3\Dih{3}D3​ on the vertices). The group D3\Dih{3}D3​ acts on the set {1,2,3}\{1,2,3\}{1,2,3} of vertices: g⋅ig\cdot ig⋅i is the image of vertex iii under ggg. The rotations rrr and r2r^2r2 move vertex 111 to vertices 222 and 333, so the orbit of vertex 111 is {1,2,3}\{1,2,3\}{1,2,3} and the action is transitive. The table of Example 1.6 shows that only eee and sss fix vertex 111, so its stabiliser is {e,s}\{e,s\}{e,s}.

1.3 Orbit–stabiliser and Lagrange

In Example 1.9 the orbit of vertex 111 has 333 elements, its stabiliser has 222, and 3⋅2=∣D3∣3\cdot2=\abs{\Dih{3}}3⋅2=∣D3​∣. We now explain this relation. Two elements of GGG send xxx to the same point exactly when they lie in the same left coset of Gx\Stab{G}{x}Gx​. So the points of the orbit of xxx correspond to these cosets.

Theorem 1.14 (Orbit–stabiliser). Let GGG act on XXX and let x∈Xx\in Xx∈X. Proof. For g,h∈Gg,h\in Gg,h∈G, gGx=hGx  ⟺  g−1h∈Gx  ⟺  g−1h⋅x=x  ⟺  h⋅x=g⋅x.\begin{aligned} g\Stab{G}{x}=h\Stab{G}{x} &\iff g^{-1}h\in\Stab{G}{x}\\ &\iff g^{-1}h\cdot x=x\\ &\iff h\cdot x=g\cdot x . \end{aligned}gGx​=hGx​​⟺g−1h∈Gx​⟺g−1h⋅x=x⟺h⋅x=g⋅x.​ Read from left to right, the chain says the map is well defined; read from right to left, that it is injective. 1.4 Conjugation and the class equation

A group also acts on itself, by conjugation. We write g ⁣x=gxg−1\conj{g}{x}=gxg^{-1}gx=gxg−1, and call this element a conjugate of xxx. 1.5 Cayley and orbit counting

By Proposition 1.10, a faithful action of GGG on XXX places GGG inside SXS_XSX​. Every group has such an action, namely left multiplication on itself.

Proof. Let GGG act on itself by left multiplication, g⋅x=gxg\cdot x=gxg⋅x=gx. Since g⋅e=gg\cdot e=gg⋅e=g, only eee fixes eee, so the kernel is 1\triv1 and the action is faithful. 1.6 Prime-power groups and Cauchy’s theorem
